Add a separate "Dub watched" counter so "On ep" ahead no longer fakes "Caught up"

- New per-user field dub_seen + dubSeen(s): how many DUBBED episodes you've actually watched, kept
  separate from "On ep" (progress), which people bump ahead to mark their overall / sub position.
- dubSeen() falls back to progress when dub_seen is unset, so every existing show and every lockstep
  dub-watcher behaves exactly as before — it only decouples once you use the new counter.
- autoDubCaughtUp() and newDubInfo() now key off dubs watched, not raw progress. So "On ep 3" with
  only 2 dubs watched now shows "🆕 New dub · Ep 3 to watch" and stays Watching, instead of a false
  "Caught up".
- UI: a 🎙️ "Dub watched" stepper on the anime card (own list, when a dub exists; green label to mark
  it personal vs the shared "Latest dub" row), setDubSeen() capped at the latest dub out, and a
  matching "Dub episodes you've watched" field in Edit (blank = track your "On ep").
- App version 2026.10.30a; service-worker cache bumped to v18.
- CHANGELOG updated
